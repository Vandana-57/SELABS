# Smart Parking Space Rental & License Validator

## Problem Statement

A smart city parking system that manages parking reservations,
validates vehicle number plates at entry gates, calculates
progressive parking charges, and detects unauthorized overstays.

## Stakeholders

- Vehicle Owner
- Parking Warden

## Deliverables

1. Requirements Table
2. UML Use-Case Diagram
3. Use-Case Flow Specification

## Repository Structure

- `requirements/` - Functional and Non-Functional Requirements
- `uml/` - UML Use-Case Diagram
- `use-case-flow/` - Detailed Use-Case Flow Specification
